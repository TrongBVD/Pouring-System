# Pouring-System

## Project Note
This project is calibrated for a specific cup with a fixed empty weight and volume. Therefore, the system may not work correctly when a different cup is used.

## Project Structure
- `build/web`, `dist`, `nbproject`, `src`, `web`, and `build.xml` are part of the Java web application.
- `SmartWaterAuditDB.sql` and `smartwaterauditdb_additional.sql` are used for Microsoft SQL Server / SQL Server Management Studio (SSMS).
- `pouring_system.cpp` contains the Arduino/ESP32 device-side code.
